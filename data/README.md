# data/ — Directory Contents

## What is stored here

| File / Folder | Source | Description |
|---|---|---|
| `final_data.json` | Hasty.ai export | Raw COCO annotations (original IDs) |
| `dataset_coco_reindexed.json` | Generated by notebook cell 3 | COCO with 0-indexed categories for YOLO |
| `classes.txt` | Generated by notebook cell 6 | Mapping: class ID → species name |
| `classes_final.txt` | Generated by notebook cell 17 | After merging rare species (<10 annotations) |
| `annotations.csv` | Generated by notebook cell 7 | Per-instance metadata |
| `images/` | **Download from Zenodo** | Raw JPEG images (not tracked in git) |
| `processed_labels/` | Generated by notebook cell 7 | YOLO-format `.txt` label files |
| `dataset/` | Generated by notebook cell 14 | Train/val split ready for YOLO training |

## Downloading the images

The images are hosted on Zenodo due to their size (~X GB).

**DOI:** `[to be added upon publication]`

After downloading, unzip the archive into this folder so that the structure looks like:

```
data/images/
├── BET-Thunnus-obesus/
│   ├── BET_abc123.jpg
│   └── ...
├── YFT-Thunnus-albacares/
│   └── ...
└── ...
```

Each sub-folder is named with the FAO 3-alpha code followed by genus and species:
`<FAO_CODE>-<Genus>-<species>`  
(e.g. `BET-Thunnus-obesus`, `BSH-Prionace-glauca`)
